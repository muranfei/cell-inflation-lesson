02 / CONCEPTS概念

BUILD THE INFLATION SIGNAL构造膨胀反馈信号

Four checks turn a congestion map into a local width update. 四个检查步骤把拥挤图转换成局部宽度更新。

01

MAP THE CENTER映射中心点

A cell belongs to the GCell containing its center. The 12 × 8 chip uses a 4 × 2 grid.单元属于其中心所在的 GCell。12×8 芯片使用 4×2 网格。

(i, j) = GCell(center)
02

MEASURE CONGESTION计算拥挤度

Demand is routing pressure; capacity is available supply. Overflow counts only the positive gap.需求表示布线压力，容量表示可用供给；只有正差值计为溢出。

c = demand / capacity
03

INFLATE LOCALLY局部膨胀

When c is above 1, scale the modeled width. Quiet cells keep their base width exactly.当 c 大于 1 时缩放建模宽度；安静单元精确保持基础宽度。

w′ = w × (1 + α(c − 1))

↻

FEED THE NEXT PASS反馈下一轮

Coordinates stay fixed. Reset to base widths before another pass so inflation does not compound.坐标不变；再次膨胀前重置基础宽度，避免反馈重复叠加。

x′ = x, y′ = y, w′ = inflated
